# SlovakGo A1 — 1,000-Slot Target Registry

STATUS: IN_PROGRESS / target-assignment phase

## Purpose

This registry makes concrete pedagogical targets for all 750 A1 expansion slots resumable from GitHub. Existing L01–L10 remain authoritative baseline content; this registry assigns targets only to L11–L40.

## Assignment rules

- Every slot has one primary target and an explicit role band.
- Targets are derived from the established A1 section focus, inventory and prerequisite graph; they are not a license to introduce deferred A2/B1 grammar.
- Repetition is intentional: NEW → REVIEW → TRANSFER → MASTERY.
- Functional case/imperative/reflexive exposure is not labelled as full productive mastery.
- A slot may combine earlier vocabulary with a new communicative context, but must have a distinct pedagogical job.
- Before JSON generation, the exact baseline overlap must be checked against the durable vocabulary matrix.
- L40 is always the section mastery check.
