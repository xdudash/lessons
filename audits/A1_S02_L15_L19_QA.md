# A1 S02 L15–L19 QA

STATUS: FULL PASS

Scope: rebuilt S02 L15–L19 under Course Architecture v2.

## Lesson roles
- L15 — preferences: `Čo máš rád?`; expresses likes using `Mám rád / Mám rada`.
- L16 — preferred activities: `Čo rád robím?`; transfers preference into familiar activity verbs.
- L17 — frequency: `Ako často?`; adds `často / niekedy` to already learned activities.
- L18 — weekend routine: `Čo robíš cez víkend?`; transfers familiar activities and frequency into a concrete weekend context.
- L19 — integration/mastery: `Povedz niečo o sebe`; combines established personal-information, language, residence and preference models in a short conversation.

## Structural QA
- All five lessons use the canonical outer `lessons` envelope.
- Lesson IDs and `order` values match S02 L15–L19.
- Each lesson contains localized title/topic/description/start screen/theory/words/exercises/final situation/result screen.
- Each lesson contains two theory screens.
- L15–L18 contain 16 exercises each; L19 contains 20 exercises for deliberate integration density.
- Exercise IDs are sequential and unique within each lesson.
- Final situations contain 3 steps and canonical `passRequirement: "3/3"`.
- No obsolete archive or duplicate lesson path is introduced.

## Pedagogical QA
- No lesson is filler: each has a distinct communicative role.
- L15 introduces preference as a productive communicative function.
- L16 reuses the preference model with activities rather than adding unrelated grammar.
- L17 introduces simple frequency with familiar verbs.
- L18 transfers the preceding activity/frequency system into a concrete weekend situation.
- L19 deliberately introduces no new grammar; it measures transfer and integration of the established S02 personal-information system.
- Retrieval and transfer are present throughout the batch.
- Reading, dialogue and learner production are included rather than relying only on recognition exercises.
- The sequence follows NEW → REVIEW → TRANSFER → INTEGRATION rather than repeating identical lessons.

## Language QA
- Slovak target phrases were checked for basic A1 usability and internal consistency.
- Russian, Ukrainian and English translations preserve the intended meaning of the Slovak target.
- Distractors are semantically distinct from correct answers.
- No known malformed Slovak sentence was intentionally retained.

## Decision
L15–L19 are accepted as the rebuilt production set for S02 under Architecture v2.

Note: S02 L13–L14 are a repository gap and are not falsely marked complete by this QA. They must be resolved before S02 is considered continuous end-to-end.
