# A1 S01–S05 Batch QA

STATUS: COMPLETE

## Scope
- A1 sections S01–S05
- 3 lessons per section
- 15 lessons total
- Production model: dynamic lesson count; 3 is the minimum and is not a global quota.

## Checks performed
- Lesson IDs and section IDs are aligned with filenames/content.
- CEFR level is A1 throughout.
- Each lesson has localized metadata, theory, vocabulary, exercises and a final situation.
- Exercise IDs are unique within each lesson.
- Correct-answer fields are present for objective exercises.
- The batch covers grammar, vocabulary, writing, reading, dialogue and real-life use.
- No lesson is created to fill a historical 10/40/1000/10000 quota.
- Progression is explicit inside each section: foundation → controlled practice → contextual/communicative use.

## Pedagogical batch map
- S01 Prvý kontakt: greetings/farewell → names → ty/vy.
- S02 O mne: identity/being → group identity → origin vs residence.
- S03 Čísla a údaje: basic numbers → phone data → age.
- S04 Ľudia a rodina: family members → possessives → identifying relatives.
- S05 Veci okolo nás: object identification → adjective agreement in common phrases → mať/possession.

## Decision
The five-section batch is accepted as the first restarted production package. Future sections may require more than three lessons when mastery analysis shows that three is insufficient. No numerical expansion is implied by this batch.
