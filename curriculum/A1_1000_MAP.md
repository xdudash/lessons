# SlovakGo A1 — 1,000-Lesson Curriculum Map

STATUS: PLANNING MAP / source of truth for A1 expansion

## Purpose

Expand the audited 250-lesson A1 baseline to exactly 1,000 A1 slots without replacing the baseline. Each of the 25 established sections has 40 slots: existing L01–L10 remain authoritative; L11–L40 are expansion slots. This file maps the complete slot space; it does not generate lesson JSON.

## Non-negotiable rules

- Existing L01–L10 in every section are preserved and remain authoritative.
- L11–L40 are planning slots until their JSON is generated and reviewed.
- Every expansion slot has a real pedagogical role: stabilization, contrast, transfer, expansion, integration, or mastery.
- Repetition follows NEW → REVIEW → TRANSFER → MASTERY; repeated vocabulary is not automatically duplication.
- Functional case, imperative and reflexive exposure must not be represented as full-system mastery.
- Systematic aspect, full case paradigms, broad verb government, full conjugation classes and complex subordination remain deferred to later levels.
- Known publishing correction: a1-s08-l06 should use the differentiated title `Bývam v byte alebo dome?`.
- Content must not be simplified to accommodate application/UI bugs.

## Allocation

| Level | Lessons | Sections | Lessons/section |
|---|---:|---:|---:|

## Expansion role template

Each section's L11–L40 is partitioned into six five-lesson bands. The band defines the pedagogical role; the concrete lesson target is chosen only after inspecting the actual baseline files and the inventory.

| Slots | Role | Required purpose |
|---|---|---|
| L11–L15 | STAB / stabilization | Rebuild and stabilize established section targets with controlled variation. |
| L16–L20 | CON / contrast | Contrast familiar forms, meanings, situations or address/register choices without introducing an advanced system. |
| L21–L25 | TRN / transfer | Move established targets into new everyday contexts; include genuine communicative transfer. |
| L26–L30 | EXP / expansion | Extend the section with adjacent high-frequency A1 language supported by the inventory. |
| L31–L35 | INT / integration | Combine section targets with earlier A1 targets in realistic multi-step tasks. |
| L36–L40 | MAS / mastery | Require independent selection/production; L40 is the section mastery check. |

## Baseline preservation registry

| Section | Existing authoritative slots | Expansion slots | Total |
|---|---|---|---:|
| S01–S25 | L01–L10 each | L11–L40 each | 25 × 40 = 1,000 |

The 250 existing lessons are not replaced by this map. Before generating an expansion lesson, the worker must inspect the actual baseline JSON and search the whole A1 corpus for overlap.

## Generation gates

1. Inspect the actual 10 baseline lesson files for the section.
2. Search the existing 250 lessons for the target before claiming an expansion slot.
3. Attach each generated lesson to a concrete inventory target and prerequisite.
4. Mark vocabulary purpose as NEW, REVIEW, TRANSFER or MASTERY; recurrence alone is not duplication.
5. Keep functional exposure distinct from productive grammar mastery.
6. Validate exercises against the established lesson JSON format; do not alter pedagogy to accommodate UI limitations.
7. Run Slovak naturalness, CEFR, prerequisite, answer-validity, duplication and progression QA.
8. Do not mark a slot complete until its JSON exists and passes review.

## Definition of done

The **map** is complete when all 1,000 slots are assigned to the section structure, role and dependency logic above. A **lesson** is complete only when its JSON is generated, reviewed, repaired if necessary, and recorded in progress.
