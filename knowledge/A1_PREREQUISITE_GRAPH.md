# SlovakGo A1 — Prerequisite Graph

This graph converts the audited 250-lesson baseline into explicit dependencies for future A1 expansion and for the A1→A2 transition.

## Status vocabulary

- **P** = productive target established in A1 baseline
- **F** = functional exposure/chunk; not full-system mastery
- **D** = deferred systematic mastery to A2+
- **R** = review/consolidation dependency

## Mastery gates for A1 expansion

A new A1 lesson may depend on:

1. **Sentence gate:** learner can understand/produce a basic clause with known subject/verb vocabulary.
2. **Question gate:** learner can handle the relevant basic interrogative or yes/no question.
3. **Agreement gate:** if adjective/demonstrative/possessive morphology is productive, required gender/number agreement must already be available.
4. **Case gate:** a case form may be used as a functional chunk before systematic case mastery, but productive manipulation requires an explicit case target and prerequisite.
5. **Tense gate:** past/future lessons require sufficient present-tense verb knowledge to anchor the new temporal contrast.
6. **Imperative gate:** imperative production must be restricted to forms whose function is already understood.
7. **Reflexive gate:** reflexive verbs may be lexical chunks; productive reflexive grammar requires later dependency work.
8. **Transfer gate:** an item counted as mastered must appear in at least one new communicative context, not only in recognition drills.

## A1 → A2 handoff

A2 should inherit these explicit dependencies rather than reintroducing them as disconnected grammar:

- A1 case chunks → systematic six-case inventory
- A1 agreement → systematic declension/agreement patterns
- A1 high-frequency verb forms → conjugation families and valency
- A1 past/future → expanded tense/aspect system
- A1 reflexive chunks → productive reflexive morphology/valency
- A1 imperative chunks → productive imperative and pragmatic variation
- A1 basic coordination → controlled subordination
- A1 lexical repetition → deliberate spaced review and transfer

## Non-negotiable boundary

**Functional exposure ≠ grammatical mastery.**

A1 content may contain `v Bratislave`, `do mesta`, `s bratom` or similar forms when communication requires them. These forms must not be counted as mastery of the entire relevant case system unless the learner has completed the corresponding productive targets.
